# Social Links Profile

## 📌 Overview
This project is a solution to the Frontend Mentor Social Links Profile challenge.  
The goal was to build a clean profile card with social media links.

## 🚀 Live Demo
https://mateusz2026.github.io/social-links-profile/

## 🛠️ Built with
- HTML5
- CSS3
- Flexbox

## 📱 Features
- Clean profile card layout
- Styled social links
- Hover effects on buttons
- Simple and modern UI

## 📚 What I learned
- Creating card layouts
- Styling buttons and links
- Working with hover states
- Improving UI consistency
